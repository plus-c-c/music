# 配乐结构与循环思路

## 目标

为 15 分钟 iGEM 展示制作一条可循环、可扩展、且能压在旁白下方的背景音轨。

总长固定为 **900 秒**。每个展示段落都使用同一套结构：

```text
原曲起始段 → 完整循环段（若干次）→ 原曲结束段 → 短暂空隙
```

## 六个展示段落

| 段落 | 叙事内容 | 情绪/音色 |
|---|---|---|
| 背景+HP | 发现问题、调研、SEED 人类实践概念 | 平缓 |
| SEED 1 | SELP 可调节 | 冷静 |
| SEED 2 | 接头、可编程模块化 | 冷静 |
| SEED 3 | 三循环：CPC、MNPs、脂质体 | 冷静 |
| 硬件 | 方便医生使用的硬件 | 硬、瞬态靠前 |
| 创业 | NexCode Bio 创业设想 | 遥远、靠后 |

## 循环规则

1. 循环只能落在原曲的拍点上。
2. 每个循环段必须是完整循环，不能截半个循环。
3. 循环接缝只做 **5 ms** 边缘淡化，不做改变时间轴的交叉淡化。
4. 段落之间留静音空隙，不直接连接。
5. 每个段落都必须有起始段和结束段；不能只重复循环段。
